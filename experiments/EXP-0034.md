# EXP-0034: Dynamic null-move reduction from evaluation margin

## Status
**ACTIVE EXPERIMENT; draft and unmerged. No strength result yet.**

## Hypothesis
When a cut node's static evaluation is already above beta, the null-move search can use a larger reduction proportional to the evaluation margin. This may save search work in overwhelmingly favorable positions while preserving tactical coverage through the existing verification-search path.

This is adapted from official Stockfish commit `9d4090e82685cca447265dcd7093d617cb34a107`, whose upstream patch changes the existing depth-only reduction to:

```cpp
Depth R = 7 + depth / 3 + std::max(0, (ss->staticEval - beta) / 256);
```

## Applicability
Accepted Crab has the same depth-only null-move reduction site in `engine/src/search.cpp`, so this candidate is applicable as a one-line isolated engine adaptation. The patch is preserved in `experiments/EXP-0034-dynamic-nmp-reduction.patch`.

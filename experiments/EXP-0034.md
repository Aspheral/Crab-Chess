# EXP-0034: dynamic null-move reduction from evaluation margin

## Final classification
**REJECTED / NOT PROMOTED.** The candidate did not demonstrate a statistically meaningful strength gain over the accepted Crab baseline. It remains outside the accepted engine chain.

## Baselines
- Accepted Crab: `917fa7fff1124343c145838aafcd59aa6c64d356`
- Immutable Stockfish 18: `cb3d4ee9b47d0c5aae855b12379378ea1439675c` (`sf_18`)
- Official SF18 deterministic bench: `2050811`

## Hypothesis
At cut nodes, increase null-move reduction when static evaluation already exceeds beta:

```cpp
Depth R = 7 + depth / 3 + std::max(0, (ss->staticEval - beta) / 256);
```

instead of the accepted-chain expression:

```cpp
Depth R = 7 + depth / 3;
```

The experiment was applied as a candidate patch to the accepted Chain 0001 base. EXP-0034 was never merged into the accepted chain.

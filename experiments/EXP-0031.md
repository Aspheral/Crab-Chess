## Upstream hypothesis
Stockfish post-SF18 commit `3e3ee33` (`Simplify HalfKAv2_hm::write_indices()`) changes the implementation of a helper named `write_indices()` in the HalfKAv2_hm NNUE feature path.

## Applicability audit
The accepted Crab tree does not contain a `HalfKAv2_hm::write_indices()` helper or an equivalent write-index path. Its HalfKAv2_hm implementation exposes `append_active_indices()`, `append_changed_indices()`, and `requires_refresh()`, with active and changed feature indices emitted directly through `ValueList::push_back()`.

Because the targeted helper and its surrounding implementation are absent, there is no faithful isolated code change to apply. Introducing a new helper or restructuring this path would be a new Crab design rather than an auditable adaptation of the upstream micro-optimization.

## Disposition
No candidate binary, patch, benchmark, strength games, or Elo estimate exists. The audit is preserved as a standalone record; accepted `main` remains unchanged. No Stockfish 18 parity or superiority claim is made.

GPLv3, inherited Stockfish copyright/upstream attribution, Crab executable/UCI identity, NNUE assets, website, and unrelated engine code are unchanged.

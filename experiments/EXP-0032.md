## Applicability check

Current Crab declares and calls `update_continuation_histories(...)`, but the accepted Crab `search.cpp` tree does not expose the upstream Stockfish implementation shape or the exact `ConthistBonus`/`CMHCMultipliers` data path used by the patch. The surrounding code is materially adapted, including Crab-local history structures and scaling expressions. Applying the upstream hunk mechanically would therefore be unsafe and would create a new, unisolated redesign rather than a faithful candidate.

Because the requested methodology requires small, auditable, applicability-first work, this candidate is archived without modifying engine semantics. A future dedicated Crab-native overflow audit may be opened only after locating the exact current implementation and defining an isolated, reproducible test harness.
